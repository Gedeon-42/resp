I care about the part nobody sees: the sync engine, the queue, the 200 milliseconds that decide whether a tool feels alive or merely loads.

I started out building websites for a design studio in Porto and got pulled deeper — first into the frontend, then into everything underneath it. These days I work across the whole stack, but my home turf is realtime: systems where state is shared, latency is visible, and correctness isn't optional.

Away from the keyboard I photograph brutalist buildings, run slowly along the Tejo, and maintain a slightly obnoxious collection of mechanical keyboards. I write about systems design when something surprises me, and I mentor two junior developers who now routinely out-argue me in code review.

Rust when a 3 a.m. pager is on the line, TypeScript for everything user-facing, Go for services that just need to quietly work for a decade. And SQL — which I consider a love language.

I care about the last four pixels and the first hundred milliseconds. Budget-driven UI work, canvas and WebGL when the DOM gives up, and CSS treated as an engineering discipline rather than an afterthought.

Event-driven by default. Postgres until it genuinely hurts, then careful surgery instead of a rewrite. I've run Kafka in production and lived to document it.
